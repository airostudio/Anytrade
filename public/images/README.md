# Images Directory

## Logo Setup

**IMPORTANT:** Save your AnyTrade logo file as `logo.png` in this directory.

### Steps:
1. Save the logo image file to: `/public/images/logo.png`
2. Recommended format: PNG with transparent background
3. Recommended size: 600x200 pixels (3:1 ratio)

The logo is used throughout the platform:
- Homepage (large size)
- Client dashboard header (small size)
- Tradesperson dashboard header (small size)

If you have a different filename or format, update the path in:
`/app/components/Logo.tsx`
